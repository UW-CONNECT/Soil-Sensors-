This folder contains the raw sensor data captured with our PCB sensor over a month in an agricultural field.


The Excel files contain processed deployment data collected during the field experiment. Depending on the sheet structure, the data may include timestamps or elapsed time, module identifiers, sensor readings, lid state information, and derived CO2 flux values.

Key variables:
- Time or timestamp: Measurement time or elapsed deployment time.
- Module ID: Unique identifier for each deployed sensor module.
- Lid status: Indicates whether the chamber lid was open or closed during measurement.
- Air temperature: Air temperature measured inside or near the chamber.
- Soil temperature: Soil temperature measured by the deployed module.
- Relative humidity: Humidity measured by the CO2 sensor module.
- Pressure: Barometric pressure measured by the pressure sensor.
- CO2 concentration: Calibrated or raw CO2 concentration readings, where available.
- CO2 flux: Derived soil CO2 emission flux rate, where available.

How to use:
The data can be opened using Microsoft Excel, LibreOffice Calc, Python pandas, MATLAB, or similar data analysis tools.
